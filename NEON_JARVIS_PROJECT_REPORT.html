01 Executive Summary & Abstract

NEON JARVIS AI is a full-featured, futuristic web-based personal AI assistant and personal operating system inspired by Iron Man's iconic J.A.R.V.I.S. companion. Engineered on Next.js 15 App Router, TypeScript, and TailwindCSS, the application synthesizes high-fidelity voice computing, multilingual intelligence (English, Urdu, and Pakistani Punjabi), real-time web querying, and autonomous media control within a cinematic, sci-fi holographic user interface.

Unlike conventional single-turn conversational chatbots that produce generic text streams, NEON JARVIS operates as an active desktop companion. It continuously listens for wake words ("Jarvis", "Assistant"), displays an audio-reactive cybernetic robotic AI face across four emotional states, and instantly executes complex real-world voice tasks such as querying live global weather, fetching real-time web intelligence, and streaming YouTube videos while responding to immediate cessation commands across regional languages ("Stop", "Ruk jao", "Bus karo", "Band karo").

02 Problem Statement & Motivation

Most commercial AI conversational interfaces suffer from three systemic constraints:

  • Monolingual & Standardized Bias: Existing systems cater predominantly to standard English, failing to recognize regional colloquial dialects such as Roman Urdu and Pakistani Punjabi naturally mixed in daily speech.
  • Passive Text-Only Modality: Standard chatbots lack physical or animated presence, failing to communicate state transitions (listening, computing, verbalizing) intuitively.
  • Action Isolation: Conventional LLM chatbots generate theoretical advice rather than directly controlling client-side actuators (such as opening, seeking, and halting media streams).

NEON JARVIS resolves these limitations by creating a tight integration between natural language understanding, real-time API routes, Web Speech / Web Audio APIs, and an expressive visual AI core.

04 Multilingual Speech & Purity Pipeline

NEON JARVIS handles code-switching between English, Urdu, and Pakistani Punjabi. The system uses a specialized intent parser that extracts linguistic markers and maps the user's intent:

  • Punjabi Detection: Identifies phonetic tokens such as "vich", "kivein", "ki haal", "tussi", "gal karo", "changa", "dasso", and responds in warm, witty Punjabi.
  • Urdu Detection: Matches vocabulary like "kaise ho", "kya chal raha hai", "mausam", "batao", "shukriya", and replies respectfully with polite Pakistani assistant phrasing ("Jee Janab, hukum karein").
  • English Detection: Replies in classic British/crisp Jarvis persona ("Right away, Sir", "All systems operational").

Speech Purity Standard (Elimination of Markdown & URL Artifacts)

A common pitfall of LLM voice agents is pronouncing raw URLs, formatting asterisks, and hash symbols (e.g. reading out "asterisk asterisk bold asterisk asterisk" or "h-t-t-p-s colon slash slash"). NEON JARVIS implements a strict sanitizer: 

// utils/cleanSpeechText.ts
export function cleanSpeechText(text: string): string {
  return text
    .replace(/```[\s\S]*?```/g, "")      // Code blocks
    .replace(/`([^`]+)`/g, "$1")         // Inline code
    .replace(/\[([^\]]+)\]\([^)]+\)/g, "$1") // Markdown links
    .replace(/https?:\/\/\S+/gi, "")     // Raw URLs
    .replace(/^#+\s+/gm, "")             // Headers
    .replace(/[*_~]{1,3}/g, "")          // Bold / Italics
    .replace(/\s{2,}/g, " ")             // Extra spaces
    .trim();
}

05 Voice Directive Engine & Instant Stop Directives

The voice pipeline allows immediate hands-free interaction. When the user speaks, speech recognition matches patterns to actionable commands:

Directive Type Voice Triggers Automated Action
Media Playback "Play [song/naat/artist]", "Coke Studio chalao", "Atif Aslam ke gane sunao" Extracts query, queries YouTube resolver, launches HUD player with autoplay.
Instant Cessation "Stop", "Ruk jao", "Bus karo", "Band karo", "Roko" Halts YouTube iframe immediately, cancels active speech synthesis, sounds stop chirp.
Live Weather "Kal ka weather batao", "Lahore weather report" Queries Open-Meteo geocoding & forecast API, displays weather card, speaks temperature in °C.
Real-Time Search "Search latest AI news", "Dhoondo SpaceX" Queries live web engine, summarizes top hits, speaks natural synopsis without URLs.
Temporal Status "Kya waqt hua hai", "What time is it" Announces current local time and date in the matching language.

06 Holographic AI Face & Sci-Fi Visual Synthesis

The visual centerpiece of NEON JARVIS is an animated robotic AI face engineered entirely with vector SVG, TailwindCSS, and Framer Motion:

  • Audio-Reactive Optics: Dual cybernetic eyes that dilate and glow with variable intensity proportional to microphone input and vocal output.
  • Oscillating Mouth Soundwave: Nine digital equalizer columns representing acoustic spectrum distribution across the lower jaw plate.
  • Bi-Directional Gyroscope: Concentric circular reticles with degree ticks rotating continuously to evoke an Arc Reactor telemetry system.
  • Procedural Particle Mesh: Interactive HTML5 canvas rendering floating cyan/purple nodes that dynamically link with laser filaments when in proximity.
